# MTG Deck Manager – Gerenciador de Decks de Magic: The Gathering

Aplicação web acadêmica desenvolvida para o curso de Ciência da Computação da SPTech.  
Permite que jogadores de Magic: The Gathering criem e organizem seus decks de Commander/EDH de forma simples e intuitiva.

## ✨ Funcionalidades

- **Cadastro e login** de usuários.
- **Criação de decks** com nome, comandante e identidade de cor.
- **Adição e remoção de cartas** em diferentes boards (Mainboard, Sideboard, Maybeboard, Wishboard).
- **Busca de cartas** por nome, custo de mana, tipo, texto e identidade de cor.
- **Importação em lote** de cartas para um deck.
- **Dashboard** com estatísticas do perfil e de cada deck.
- **Mural de avisos** Avisos sobre novos lançamentos de edições, e sobre atualizações do usuário.
